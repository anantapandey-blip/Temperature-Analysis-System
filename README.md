# Temperature-Analysis-System
A Temperature Analysis System built with Python and NumPy to analyze weekly temperatures across multiple cities.

## Purpose

The purpose of this project is to practice using **NumPy for handling and analyzing real-world style data**. It focuses on applying array operations, filtering, indexing, aggregation, random data generation, and file handling through a simple menu-driven system.

##  Concepts Used

* NumPy arrays
* Array slicing and indexing
* `np.mean()`, `np.max()`, `np.min()`
* Boolean filtering
* `np.where()`
* `np.concatenate()`
* `np.vstack()`
* Random number generation
* File handling
* Exception handling
* `while` loop and menu-driven programming

##  How to Run

```bash
pip install numpy
python temperature_analysis.py
```
